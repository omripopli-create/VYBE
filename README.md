# VYBE MVP

אב־טיפוס עובד של VYBE.

## הפעלה
פתחו את `index.html` בדפדפן.

## מה עובד
- מפה מדומה עם VYBE Score
- רשימת מקומות
- Find my VYBE לפי תקציב, מרחק וסגנון
- עמוד פרטי מקום
- Post a VYBE
- שמירת דיווחים ב-localStorage
- כפתור מיקום בסיסי

## מה צריך לגרסה אמיתית
- React Native / Flutter
- מפה אמיתית (Google Maps / Mapbox)
- Backend + Database
- משתמשים והתחברות
- העלאת תמונות/וידאו
- moderation
- חיבור לעסקים ואירועים
- מערכת דירוג עמידה בפני ספאם
